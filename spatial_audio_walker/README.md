# Spatial Audio Walker

使用 Unity/Unreal 引擎风格的空间音频系统，模拟真实行走空间和回声效果。

## 功能

- 3D 空间建模（房间尺寸、物体位置）
- 空间音频（HRTF 双耳渲染）
- 早期反射和混响
- 多场景行走路径
- 完整的声学数据记录

## 技术栈

- Python + NumPy + SciPy（音频处理）
- 基于游戏引擎的声学模拟算法
- 支持 WAV 格式输出

## 生成数据集

- 10+ 个行走片段
- 每个片段包含：
  - 视频帧（64×64）
  - 空间音频（WAV）
  - 声学数据（JSON）
  - 房间信息（JSON）
